            2. Start AlloyDB Auth Proxy Locally
            
          

          
./alloydb-auth-proxy \

  --port 5432

        


        

          

            3. Run Standalone Batch Pipeline CLI
            
          

          
python scripts/batch_pipeline.py --input-dir sample_docs --mode online
